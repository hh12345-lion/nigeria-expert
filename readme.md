# Africa Expert Witness

SEO-optimized lead-generation website for [africaexpertwitness.com](https://www.africaexpertwitness.com).

## Stack

- Next.js (App Router), TypeScript, Tailwind CSS
- Static export-ready SSG
- Formspree contact form

## Setup

```bash
npm install
cp .env.example .env.local
# Set NEXT_PUBLIC_FORMSPREE_FORM_ID
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Environment

See `.env.example` for required variables.
